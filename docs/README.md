# Screenshots

This folder holds screenshots displayed in the root [`README.md`](../README.md).

## Naming convention

Save your screenshots with these exact filenames so the README's image references work out of the box:

| Filename | What to capture |
|---|---|
| `dashboard.png` | `/dashboard` — XP, streak, level, current path tiles |
| `path-view.png` | `/path/1` — milestones trail + polyglot code terminal |
| `code-editor.png` | The full SkillSyncTerminal with code, test cases, and results |
| `leaderboard.png` | `/leaderboard` — top users ranking with weekly/all-time toggle |
| `admin.png` | `/admin` — user management table (log in as admin first) |
| `login.png` | `/login` — landing/sign-in page |

## Tips for great screenshots

- **Browser**: Chrome or Edge in **incognito** (no extensions, no bookmarks bar)
- **Window size**: **1440×900** or **1920×1080** for crisp desktop captures
- **Theme**: Use a clean light or dark mode — pick one and stick with it across all screenshots
- **Data**: Seed a few sample users with XP/streaks so the leaderboard and admin pages look populated
- **Format**: PNG (lossless), not JPG
- **File size**: Keep each under **500 KB** — use [tinypng.com](https://tinypng.com/) if needed so the README loads fast

## How to capture on Windows

1. Open the app at `http://localhost:5173`
2. Press `Win + Shift + S` for the Snipping Tool
3. Drag to select the area
4. The screenshot is copied to your clipboard
5. Open Paint (or any editor) → `Ctrl + V` → `Ctrl + S` → save as PNG into this folder

Once you have the screenshots saved here, the README's image references will pick them up automatically.
