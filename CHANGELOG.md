# Changelog

All notable changes to SkillSync are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- Renamed project from PathPulse to SkillSync (frontend, backend, package names, config, docs)

## [1.0.0] - 2026-08-13

### Added
- Initial public release
- React 19 + TypeScript + Vite frontend
- Spring Boot 3.3 + Java 21 REST API backend
- JWT-based authentication with role-based access control
- Curated learning paths with multi-milestone progression
- Polyglot code editor supporting JavaScript, Python, Java, C++, and C
- XP, level, and daily-streak tracking
- Leaderboard with weekly, monthly, and all-time ranges
- Admin dashboard for user and content management
- MySQL 8 persistence with auto-DDL schema management
- JSON-seeded catalog (skills, paths, milestones, code tasks) on first boot
- Default admin bootstrap account on first backend start
